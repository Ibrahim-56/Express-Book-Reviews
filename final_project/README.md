# Express Book Reviews — Starter Project

Node.js and Express starter project for a book-review API. Several route handlers are still placeholders, so this is currently an incomplete learning exercise rather than a finished API.

## Dependencies

- Node.js and npm
- Express
- Express Session
- JSON Web Tokens

## Install and start

```bash
npm install
npm start
```

The server is configured to listen on port 5000. Some routes return a placeholder response until their implementation is completed.

## Current limitations

- Registration, login, book lookup, and review routes are not fully implemented.
- The test script is a placeholder and exits with an error.
- Session secret management and authentication require further work.

Do not use this application with real user data until authentication, session handling, validation, and automated tests have been completed.
